# Integrated Statistical Analysis Report

## Project Overview

This project presents an **Integrated Statistical Analysis** focused on probability, random variables, probability distributions, Venn diagrams, contingency tables, conditional probability, event relationships, and Bayes' Theorem.

The analysis is based on a dataset containing information about students, including study hours, attendance, group discussion participation, and final exam results.

## Topics Covered

### 1. Understanding the Basics of Probability
- Definition of probability
- Experiment
- Sample Space
- Event
- Dataset-based probability examples

### 2. Types of Probability
- **Empirical Probability:** Calculated from historical or observed data.
- **Theoretical Probability:** Calculated using logical reasoning and assumptions about equally likely outcomes.

### 3. Random Variable & Probability Distribution

A discrete random variable is defined as the **number of students passing the final exam out of randomly selected students**.

The report includes:
- Probability distribution table
- Probability formula
- Mean calculation
- Variance calculation

### 4. Venn Diagram Analysis

From the dataset of **200 students**:

| Condition | Students |
|---|---:|
| Study Hours > 10 | 137 |
| Attendance > 80% | 93 |
| Both Conditions Met | 68 |
| Neither Condition Met | 38 |

### 5. Contingency Table

The relationship between **group discussion participation** and **final exam results** is analyzed.

| Group Discussion | Fail | Pass | Total |
|---|---:|---:|---:|
| No | 47 | 32 | 79 |
| Yes | 54 | 67 | 121 |
| **Total** | **101** | **99** | **200** |

The report covers:
- Joint Probability
- Marginal Probability
- Conditional Probability

### 6. Understanding Relationships

The analysis explains:
- Conditional probability
- Mutually exclusive events
- Independent and dependent events

The report concludes that **group discussion participation and final exam performance are statistically dependent**, because participation changes the probability of passing.

### 7. Bayes' Theorem

Bayes' Theorem is applied using historical student data.

The final conclusion in the report is:

> Given that a student has high attendance, there is a **77.78% probability** that they passed the exam.

## Key Insights

- The dataset contains **200 students**.
- **99 students passed** the final exam.
- **121 students participated** in group discussions.
- **67 students** who participated in group discussions passed.
- Students with high attendance show a strong relationship with passing the final exam.
- Conditional probability and Bayes' Theorem help interpret these relationships.
